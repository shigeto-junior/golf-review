# 記録する項目（案）

The Grint ではスコアとコースマップを記録している前提で、このアプリは「なぜその打数になったか」を振り返るための項目に絞る。
ラウンド中に 1 ホール 10 秒程度で入力できることを目標にする。

## ホールごと

| 項目 | 入力方法 | 何がわかるか |
| --- | --- | --- |
| 打数 | 数字ボタン | スコア |
| パット数 | 数字ボタン | パット数、3パット率 |
| ティーショットのクラブ | 1W / 3W / 5W / UT / アイアン / その他 | クラブ別のFWキープ率、ミス傾向 |
| ティーショットの結果（パー3以外） | FWキープ / 左ミス / 右ミス / チョロ・トップ | FWキープ率、左右どちらに曲がりやすいか |
| グリーンを外した方向（パーオンしなかったとき） | 左 / 右 / ショート / オーバー | アプローチショットの傾向 |
| 1パット目の距離 | 1m以内 / 1〜3m / 3〜6m / 6m以上 | 距離別のパット成績 |
| ペナルティ | 0 / 1 / 2… | OB・池でどれだけ落としているか |
| バンカーに入ったか | はい / いいえ | バンカーからの寄せの成績 |
| ひとことメモ | 任意 | 振り返り用 |

## 自動で計算するもの

- パーオン: (打数 − パット数) ≤ (パー − 2)
- 寄せワン（パーオンしなかったホールでパー以下）
- 3パット率、平均パット数
- FWキープ率（全体／クラブ別）
- ミスの左右比率

## ラウンドごと

- 日付、コース名、ティー、各ホールのパー、メモ

## コースメモ

- コースごとに「全体メモ」と「ホール別メモ」（例: 右OB、ティーショットはUTで左サイドへ）
